欢迎使用 · 灵感开工

让每个好想法，都有下一步 ✨

无需注册、无需安装。只需打开网页，就能把灵感整理成行动计划。

  1. 收集灵感：粘贴视频分享文案、网页链接，或者直接输入想法。
  2. 生成行动卡：点击「生成行动卡」，系统按主题分类并提供三步行动建议。
  3. 安排任务：设置优先级和截止日期，使用「今日推荐」挑选最值得做的事。
  4. 执行和打卡：在行动卡中更新状态，开启「7天挑战」，逐天勾选完成。
  5. 记录与检索：记录成果、按关键词搜索，也可导出 JSON 文件备份数据。
使用前须知：数据仅保存在当前设备的浏览器中，不会自动跨设备同步；清理浏览器数据可能导致丢失，请定期导出备份。当前会尝试通过第三方元数据服务解析公开链接的标题和简介；受平台限制时可能失败，不读取私人收藏或视频画面。提交链接会将该网址发送给第三方元数据服务。
